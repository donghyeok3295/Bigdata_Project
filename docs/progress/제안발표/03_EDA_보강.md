## 2단계 — 다변량 EDA 보강 (완료)

**통합 테이블** `work/ref/eda_multivar.parquet` — 호출(call) 단위로 `sgg_load, center_load, avg_speed_kmh, dist_km, hour, dclr_dow, late` 전부 결합. 계산 방식:
- `sgg_load`: 전체 기록(raw)에서 **신고시각(dclr)** 기준 60분 rolling count, 구별, 자기 자신 제외(closed='left')
- `center_load`: 전체 기록에서 **출동시각(dspt)** 기준 60분 rolling count, 센터별 (규칙상 센터활동량은 출동시각 기준)
- `avg_speed_kmh`: `work/speed/speed_by_gu_hour.parquet`에서 구+신고 직전 완결 시간으로 결합 (결측 0.20%, 기존 문서 수치와 일치 확인됨)

**데이터 품질 이슈 발견**(이번에 처음 확인): `dist_km`에 음수 4건, 100km 초과 15건(최댓값 2024km, 명백한 오류) 존재. 상관분석에서 이 19건 제외. 06_EDA_결과.md에 있던 "음수 거리 건수 확인" 미완 항목이 이걸로 해소됨 — **단, 아직 정식 제외 규칙으로 명세서에 반영은 안 함.**

**상관행렬(Spearman, n≈548,570)**:
| | sgg_load | center_load | avg_speed | dist_km | hour | late |
|---|---|---|---|---|---|---|
| sgg_load | 1.000 | 0.326 | -0.159 | 0.169 | 0.161 | **0.110** |
| center_load | | 1.000 | -0.051 | 0.034 | 0.070 | **0.007** |
| avg_speed | | | 1.000 | -0.029 | -0.433 | **-0.050** |
| dist_km | | | | 1.000 | 0.047 | **0.403** |

**중요**: `dist_km`-`late` 상관(0.403)이 RQ1/RQ2 변수들보다 훨씬 큼(당연함, 물리적으로 직결). 발표에서 "거리는 중요하지 않다"처럼 말하면 이 표와 모순되어 보이니 주의. "거리도 중요하지만, 거리로 설명 안 되는 추가 변동이 있다"로 표현해야 함.

**VIF(다중공선성)**: sgg_load 1.20, center_load 1.14, avg_speed 1.33, dist_km 1.03, hour 1.33 — **전부 10 미만, 다중공선성 문제 없음**. RQ1+RQ2 결합 모델(RQ3) 진행에 통계적 문제 없다는 근거.

**교차 층화표** (구활동량 효과가 다른 변수의 착시인지 검증):
- `eda/16_cross_load_speed.png`: 정체 5분위 × 활동량 5분위. **모든 정체 구간에서 활동량 Q1→Q5 차이 양수**(+7.1p ~ +19.5p). 정체 심할 때 효과가 원활할 때보다 2~3배 큼(상호작용 존재)
- `eda/17_cross_load_hour.png`: 시간대 4구간 × 활동량 5분위. **모든 시간대에서 효과 유지**(+6.6p ~ +16.4p)
- `eda/18_stratified_trend_speed.png`: 정체 5구간별 (연속값 sgg_load vs late) Spearman 상관 + 95%CI 선그래프. **5구간 전부 p<0.001.** 정체 심한 구간 ρ=0.131~0.136 vs 원활한 구간 ρ=0.048 — 약 2.8배 차이

**결론**: 구활동량 효과는 정체·시간대의 착시가 아니라 독립적으로 실재함. 단, 정체와 상호작용(정체 심할 때 효과 증폭)이 있다는 추가 발견.

## 3단계 — 관외출동 비율 EDA (완료)

0단계 매핑을 EMS 코호트(`work/seoul_2024_clean.csv`)에 조인.

- 매칭률 96.1%(528,692/550,251), 나머지는 서울 밖 소방서(정상 노이즈)
- **관외출동 비율: 19.08%**(100,857/528,692) — 신고 구(`sgg_nm`) ≠ 실제 출동 센터 소속 구(`center_sgg`)
- 관내 43.8% vs 관외 67.0% 초과율. **chi2=17,579.4, p<0.001**, 95%CI(43.67~43.97 vs 66.72~67.30) 전혀 안 겹침 → `eda/19_out_of_jurisdiction.png`
- 구별 관외출동 비율: 성동구(33.5%)·동작구(33.1%) 최고, 강동구(4.2%) 최저

**거리와의 관계 검증** (교수님 지적: "그냥 거리가 멀어서 아니냐"):
- `out_of_jur`-`dist_km` 상관 r=0.276, 평균거리 관외 2.51km vs 관내 1.69km — **거리가 어느 정도는 설명함**
- **거리 5분위로 고정해도 효과가 그대로 남음**: D1(최단)+7.7p ~ D5(최장)+9.6p, 전 구간 양수 → `eda/20_outofjur_controlled_by_dist.png`
- **결론**: 원래 23.2p 차이 중 약 14p는 거리가 매개, 나머지 약 8~9.6p는 거리로 설명 안 되는 독립 효과

**메커니즘 분해** (신고→출동 "준비시간" vs 출동→도착 "이동시간"으로 분리):
- 준비시간 차이: 관외-관내 거의 0 (±0.1분 이내, 거리 구간 무관)
- 이동시간 차이: **전 거리구간에서 양수**, 거리 멀수록 커짐(+0.57분 D1 → +1.59분 D5)
- → **"출동 결정에 조율시간이 더 걸린다" 가설은 탈락. "실제 이동이 비효율적이다" 가설 쪽으로 기움.** 다만 이게 "낯선 구역이라 진짜 비효율"인지 "`grnds_dstnc` 기록 자체가 관외출동 건에서 부정확"인지는 **확정하지 못함** — 한계로 명시 필요
