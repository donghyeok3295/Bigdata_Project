# 09. 중간발표 1차 모델(G0) 구현 계획

날짜: 2026-10-26

전제: D-014(제안)에 따라 중간발표는 단순 기준·B0·LR·G0, D+/D−, 보정까지. 활동량·강수·교통은 기말. 서버 정제본(`/clean/ems_cohort` 3,345,090건)과 2024 대조 완료. 이 문서는 `design` 에이전트 계획과 사용자 승인(2026-10-26)을 기록한 것이다. 시험 구간(2025)은 열지 않는다.

---

## 승인된 결정 (구현 기준)

| # | 결정 | 근거 |
| --- | --- | --- |
| 1 | 안전센터가 아닌 기록(현장대응단·항공대 등 약 4%)은 **행을 유지**하고 `unit_type=other`, `out_of_jur=NaN`. 코호트는 바꾸지 않는다 (팀 합의 시 변경 가능) | 설계 팀 확인 1(A안) |
| 2 | `is_holiday`는 `configs/holidays_kr.yaml`에 직접 작성(새 패키지 없음, 주말 제외). **팀원이 원문과 대조하기 전까지 "팀 대조 전" 표시**. 늦어지면 결과는 "임시" | 규칙 13 |
| 3 | 보정 후 평가는 calib를 날짜 블록 2-fold cross-fit으로 보고. 보정 전 지표도 함께 | 낙관 편향 방지 |
| 4 | 단순 기준·B0는 D+/D− 구분이 없으므로 "D 무관 1행"으로 보고 | 거리 없이 B0 정의 불가 |
| 5 | LightGBM 튜닝은 `n_trials=20`, 시드 42, 같은 탐색 공간. 기말 모든 LightGBM이 같은 예산 사용 | 규칙 6 |
| 6 | 라벨 `y_late = resp_min > 8` (서버 `late` 열과 100% 일치, `>= 8`과는 97.4%) | 설계 확인 |
| 7 | `dist_km` 음수·100km 초과는 NaN(D-009). 6km 초과는 `out_of_range=1`(피처 아님, 보고용) | D-009 |
| 8 | 시각은 **문자열**로 서버에서 내보낸다(Spark→parquet UTC 변환으로 hour가 9시간 밀리는 사고 방지) | 설계 위험 1 |

## 서버에서 내보내는 열 (최소 열)

`call_id`, `dclr_str`(yyyy-MM-dd HH:mm:ss), `center_id`, `cntr_nm`, `sgg`, `dist_raw`, `resp_min`, `year`. 증상·심정지·개인 식별 열은 넣지 않는다. 2019~2024는 `base_v1/`, 2025는 `base_v1_test/`(로컬로 가져오지 않음).

## 구현 목록 (로컬, pipeline-impl)

1. 설정: `configs/data.yaml`에 `dist_error_max_km: 100`, `splits_dir: data/splits`, `base_dir: work/base_v1`, `holidays: configs/holidays_kr.yaml`. `configs/features.yaml`에 `base_features`. `configs/models/tuning.yaml`(n_trials 20, seed 42, early_stopping_rounds 100, n_estimators 5000, 탐색 공간: num_leaves [15,255], learning_rate log [0.02,0.2], min_child_samples [20,500], feature_fraction [0.6,1.0], bagging_fraction [0.6,1.0] + bagging_freq 1, lambda_l2 log [1e-3,10], cat_smooth [1,50]; LR의 C는 로그 격자 6개), `configs/models/{simple,b0,lr,g0}.yaml`
2. `configs/holidays_kr.yaml` 초안(2019~2025, 관공서 공휴일·대체·임시 포함, 주석 "팀 대조 전")
3. `src/models/features.py` — `load_holidays`, `make_label`, `clean_dist`, `unit_type_of`(안전센터→center, 현장대응단→field_unit, 구조대→rescue, 그 외→other), `add_out_of_jur`(`work/ref/center_to_sgg.parquet`), `add_time_features`(dow 월=0), `build_base_table`; 범주(center_id·sgg)는 train에서만 목록 생성
4. `src/models/splits.py` — `build_splits`(2024 이후 연도가 입력에 있으면 실패), `fix_categories`, `load_split`(`test`는 `final_eval=False`면 ValueError)
5. `src/models/metrics.py` — Brier, log loss, AUC, AP, calibration slope·intercept(numpy 구현, p는 [1e-6,1-1e-6]로 자름), 날짜 블록 부트스트랩
6. `src/models/baselines.py` — `SimpleRateModel(min_n=50)`: 센터×시간 지연율, 50건 미만은 센터 평균 → 전체 평균
7. `src/models/train.py` — `--config --dist plus|minus [--n-trials]`. LightGBM 랜덤 탐색(valid log loss로 선택), LR(train에만 fit한 OneHot+StandardScaler, 결측은 train 중앙값 + `dist_missing`). 가중치 키(`scale_pos_weight`, `is_unbalance`, `class_weight`)가 설정에 있으면 실패. 산출물 `models/{name}/{dplus|dminus}/{run_id}/`
8. `src/models/calibrate.py` — calib 2024로 isotonic(Platt는 비교용), `calibrator.pkl`, `threshold.json`(보정 확률 상위 20%)
9. `src/models/evaluate.py` — valid·calib 평가(calib는 보정 전과 cross-fit 보정 후), `--final-eval`은 `freeze-v1` 태그 없으면 거부, `results/midterm_metrics.csv`, `results/calibration_midterm.csv`
10. `src/pipeline/export_base.py` — 서버 내보내기 스니펫 모듈화
11. 테스트(합성 샘플만): T-01(8.0→0, 8.01→1, 서버 `late`와 불일치 assert), 피처 경계, T-03·T-04(분할 겹침 없음, test 가드, train에 없던 범주는 valid에서 NaN), 지표(sklearn 값과 일치, 잘 보정된 확률이면 slope≈1), 기준선 대체 순서, 규칙 5 가드, T-05 스모크(합성 1만 행, `n_trials=2`, 3분 이내)
12. `ruff format . && ruff check . && pytest -q` 통과

데이터가 도착한 뒤(별도 단계): `build_base_table`과 hour 분포 대조(`work/seoul_2024_clean.csv`의 hour와 일치), 분할 생성, simple·B0·LR·G0 × D+/D− 학습·보정·평가, `notebooks/06_중간발표_예비결과.ipynb`.
