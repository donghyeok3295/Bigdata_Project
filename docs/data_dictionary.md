### 1.2 처리 규칙 (반드시 지킬 것)

| 문제 | 처리 |
| --- | --- |
| 결측이 `\N` 문자열 | `na_values=["\\N", ""]` |
| 도착시각 등 일부가 **공백 문자** | 읽은 뒤 `.str.strip().replace({"": None})` |
| 컬럼명이 연도별로 다름 | **2023년 이전 대문자**, 2024년부터 소문자 → `df.columns.str.lower()` |
| 시각 앞자리 0 누락 (`90100` = 09:01:00) | `.str.zfill(6)` 후 일자와 결합 |
| 같은 이름 조직이 여러 소방서에 존재 | `center_id = frstn_nm + " " + cntr_nm` |
| 서울 신고에 타 지역 소방서 1건씩 혼입 | 소수 건수 조직 제외 |
| 같은 센터·같은 시각 2건 기록 (약 3만 쌍) | 한계로 기록, 활동량이 2의 배수로 튈 수 있음 |

## 2. 서울시 차량통행속도

| 항목 | 내용 |
| --- | --- |
| 출처 | 서울시 (TOPIS / 열린데이터광장) |
| 단위 | **한 행 = 날짜 × 도로구간(링크)**, 시간대별 평균 속도가 가로로 24칸 |
| 값 | km/h |
| 시간 범위 | **01~24시 전체** (야간 포함). 단 2020년 12월은 원본 자체가 12/14일까지만 있고 12/15~12/31(17일)이 통째로 결측(TOPIS 원본 결함) |
| 기간 | 2019-01-01 ~ (확인 필요) |

### 2.1 컬럼

| 컬럼 | 의미 | 사용 | 예시 |
| --- | --- | --- | --- |
| `일자` | YYYYMMDD | ✅ 조인 키 | 20190101 |
| `요일` | 한글 1자 | 참고 | 화 |
| `도로명` | 도로 이름 | 참고 | 4.19로 |
| `링크아이디` | 도로구간 고유 ID | ✅ 구간 식별 | 1080012200 |
| `시점명` / `종점명` | 구간 시작·끝 지점 | 참고 | 아카데미하우스 |
| `방향` | 상행/하행 | 참고 | 상행 |
| `거리` | 구간 길이(m) | ✅ **가중평균 가중치** | 1179 |
| `차선수` | 차로 수 | 참고 | 1 |
| `기능유형구분` | 도로 등급 | 참고 | 보조간선도로 |
| `도심/외곽구분` | | 참고 | 외곽 |
| **`권역구분`** | **자치구명** | ✅ **구 매핑 키** | 강북구 |
| `01시` ~ `24시` | 해당 시간대 평균 속도 | ✅ 값 | 44.37 |

### 2.2 가공 방침

1. **세로로 펴기**: 24개 시간 컬럼 → `일자 · 시간 · 링크아이디 · 권역구분 · 거리 · 속도` 형태
2. **구 단위 집계**: 같은 구·같은 시간의 속도를 **구간 거리로 가중평균** (짧은 골목과 긴 간선도로를 같은 무게로 두지 않기 위함)
3. **평소 속도**: 학습 기간(2019~2022)만으로 구 × 요일유형(평일/주말·공휴일) × 시간대 평균
4. **정체 지수**: `cong_idx = 해당 시각 직전 시간의 구 평균 속도 ÷ 평소 속도` — 1보다 작으면 평소보다 막힘

### 2.3 주의

- `권역구분`에 자치구명이 들어 있어 **별도 도로→구 매핑이 필요 없다.**
- 시간 컬럼이 `01시`~`24시`다. `24시`는 23:00~24:00 구간으로 해석한다(자료 설명 확인 필요).
- 실시간 도로소통 API와 도로 목록·집계 방식이 다를 수 있다. 차이를 확인해 D-005에 기록한다.
