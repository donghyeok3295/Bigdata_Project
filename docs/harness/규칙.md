## 1. 기술 스택

Python 3.11 · PySpark 3.5 (배치 + Structured Streaming) · Hadoop HDFS · pandas · pyarrow · LightGBM · scikit-learn(보정) · SHAP · OSMnx · GeoPandas · NetworkX · FastAPI · Pydantic v2 · Leaflet · pytest · ruff · Docker Compose · GitHub Actions · kind/k3d

새 패키지는 PR 설명에 이유를 적는다. 로컬 분석용 pandas는 `py -3.12` 환경에 설치돼 있다.

## 2. 명령

```bash
cp .env.example .env && pip install -e ".[dev]"
ruff format . && ruff check . && pytest -q

docker compose --profile pipeline up -d
python -m src.pipeline.run --step all        # 또는 convert / seoul_all / cohort / activity / splits
python -m src.traffic.build                  # speed_hist, speed_norm
python -m src.benchmark.pandas_vs_spark

python -m src.collector.run                   # 실시간 수집기
python -m src.models.train --config configs/models/g4.yaml --dist plus    # plus | minus
python -m src.models.calibrate --run models/g4/plus/<run_id>
python -m src.models.evaluate --run models/g4/plus/<run_id>               # 검증·보정 구간만
python -m src.models.evaluate --run ... --final-eval                     # 시험 구간, freeze-v1 이후 팀 합의 시에만

docker compose --profile stream up -d        # 재생 스트림
docker compose --profile app up -d           # 시스템
kind create cluster --name ems && kubectl apply -f k8s/   # K8s 최소 배포
```

실제 명령이 다르면 코드를 확인하고 이 절을 고친다.

## 4. 절대 규칙

요청을 받아도 따르지 말고 이유를 설명한다.

1. **누출 금지**: 모든 피처는 신고 시각 `t` 이전 정보만. 활동량은 `[t−60분, t)`, 자기 자신 제외. 정체·강수는 직전 완결 시간·직전 정시 값.
2. **활동량은 전체 기록에서**: `ems_seoul_all`(정제 전)에서 도시·구·센터 3층을 세고, 라벨 평가는 `ems_cohort`(정제 후)로.
3. **시험 구간 보호**: 2025년은 `--final-eval`에서만. `freeze-v1` 태그 전에는 열지 않는다.
4. **평소 속도는 학습 기간(2019–22)으로만** 계산한다.
5. **가중치 없이 학습하고 보정기로 확률을 만든다**. `scale_pos_weight`, `class_weight` 금지.
6. **공정 비교**: 같은 분할·시드 42, 모델마다 같은 탐색 공간·같은 시행 횟수로 각각 튜닝.
7. **확률과 경로 정보를 섞지 않는다**: 순위는 보정된 `p_ontime`으로만.
8. **수치 조작 금지**: 결과는 스크립트 실행 결과로만.
9. **데이터 반출 금지**: 원본·실제 샘플을 커밋하거나 외부 AI 서비스에 올리지 않는다. CI는 합성 샘플. (D-006)
10. **비밀 키 금지**: `.env`와 환경변수만.
11. **표현 금지**: "최적 경로", "최적 배치", "배차 개선", "구급차 수", "성능 향상 입증", "골든타임 보장", "법규 무시·예외"(→ 긴급자동차 특례). 면책 문구 필수.
12. **스키마·규칙 변경** 시 명세서와 `DECISIONS.md`를 같이 수정.
13. **인용·참고문헌을 AI가 만들지 않는다**: 후보를 찾아 제시만 하고, 팀이 원문 확인 후 기재. (협업 가이드 10절)

## 5. 데이터 계약 요약 (상세: 명세서 3절)

- 원본은 모두 문자열로 읽고 `\N`·공백을 결측 처리, 컬럼명 소문자 통일(2023년 이전 대문자). 시각은 `zfill(6)` 후 일자와 결합, 앞 시각보다 이르면 다음 날
- **위치 최대 해상도는 시군구(`sgg`)**. 읍면동·좌표 없음, `sgg`가 기본 피처. `sgg_nm`은 **신고 위치**의 구이며 출동 센터의 소속 구가 아니다
- 분석 단위: 출동기록 1건 (`call_id = rlf_rptp_no`)
- `center_id = frstn_nm + " " + cntr_nm` (공백 정규화). `unit_type`: `center` / `field_unit` / `rescue`, 시스템 후보는 `center`만
- 라벨 코호트 제외: 취소 → 시각 결측 → 0분 이하·시각 역전 → 180분 초과. **60~180분은 유지**
- `dist_km = grnds_dstnc`(대원 기재 정수 km, 사후 기록 가능성) → 모든 모델 D+ / D− 두 설정. `grnds2/3_dstnc` 사용 금지
- `dist_km` 음수·100km 초과는 **값만 결측 처리하고 행은 유지**. 6km 초과는 오류가 아니라 `out_of_range` (D-009)
- `out_of_jur` = 신고 구(`sgg_nm`) ≠ 센터 소속 구(`center_sgg`). 기본 피처, 정적이라 누출 없음. 매핑은 `work/ref/center_to_sgg.parquet` (D-008)
- 3층 활동량: `city_calls_60`, `sgg_calls_60`·`sgg_dspt_60`, `center_dspt_60`(출동 시각 기준)
- 강수: ASOS 108 직전 정시, 무강수와 결측 구분(`rain_missing`). 적설 사용 안 함
- 복귀: `cbk_ymd` 없으면 출동일 + `cbk_tm`, 앞서면 다음 날, 12시간 초과 null. 복원율 90% 미만이면 `open_dspt_at_t` 미사용
- 심정지·증상 컬럼은 입력 피처 금지
- 분할: train 2019–22 / valid 2023 / calib 2024 / test 2025 (D-007)
- 거리 상위 1%(6km) 초과는 `out_of_range`

df.columns = df.columns.str.lower()

### 정체 지수

- 속도 원본(TOPIS)의 `권역구분` = EMS `sgg_nm` (25개 구 완전 일치, 매핑표 불필요)
- 시간 컬럼 표기가 `01시`/`~01시`로 섞여 있다 → 병합 전 정규화 필수
- `speed_hist`: 구 × 날짜 × 시간 평균 속도 (`work/speed/speed_by_gu_hour.parquet`, `hour=h`는 `[h-1시, h시)` 구간)
- `speed_norm`: **학습 기간(2019~2022)만**으로 구 × 요일유형 × 시간대 평균
- `cong_idx(t) = speed_hist(구, t의 직전 완결 시간) / speed_norm(...)`. 자료 없으면 `1` + `cong_missing=1`
- 과거·실시간을 **같은 함수**(`src/traffic`)로 계산. 2020-12-15~31은 원본 결측

## 6. 코딩 규칙

- 공개 함수는 타입 힌트와 한 줄 docstring
- 경로·상수는 `configs/*.yaml`
- Spark 단계마다 입력·출력 행 수와 소요 시간 로깅
- 대용량 원본을 pandas로 통째로 읽지 않는다 (벤치마크 제외)
- 외부 API는 타임아웃·재시도·캐시·실패 시 평소값 + 경고, 테스트에서는 모의 객체

## 7. 작업 방식

1. **이해**: 관련 요구사항 ID와 명세서 절을 읽는다.
2. **계획**: 바꿀 파일과 방법을 3~5줄로 제시. 스키마·규칙·평가 설계 변경이면 멈추고 확인받는다.
3. **구현**: 작은 단위로, 관련 없는 파일은 건드리지 않는다.
4. **검증**: `ruff`, 관련 `pytest`. 계산 로직에는 테스트 추가.
5. **보고**: 변경 / 요구사항 / 검증(명령·행 수·지표) / 남은 일

## 9. 자주 하는 실수

| 실수 | 올바른 방법 |
| --- | --- |
| 시각 문자열을 그대로 파싱 | `zfill(6)` 후 날짜와 결합, 자정 넘김 보정 |
| 코호트에서 활동량 계산 | 전체 기록에서 계산해 코호트에 조인 |
| `cntr_nm`만으로 센터 구분 | `frstn_nm + cntr_nm` |
| 복귀 날짜를 신고일로 채움 | 출동일 기준 + 역전 시 다음 날, 12시간 초과 null |
| 강수 빈칸을 모두 0 | 무강수/결측 구분 |
| 평소 속도를 전체 기간으로 계산 | 학습 기간만 |
| 과거·실시간 정체 지수를 다른 코드로 | `src/traffic` 공용 함수 |
| 클래스 가중치 후 출력을 확률로 | 가중치 없이 학습 + 보정기 |
| 속도 파일을 헤더 확인 없이 concat | `~01시` → `01시` 정규화 후 assert |
| 노트북 셀 수정 후 정의 셀 미실행 | 정의 셀부터 재실행 또는 Restart & Run All |
| ΔAUC 소수점 넷째 자리를 개선으로 서술 | 주 지표 Brier·log loss, ΔAUC 0.005 미만 무시 |
| 행 단위 부트스트랩 | 날짜 블록 |
| 60분 초과 기록 삭제 | 유지, 180분 초과만 제외 |
| 경로 ETA를 순위에 반영 | 순위는 `p_ontime`만 |
| 시험 점수 보고 설정 변경 | 동결 후 1회 평가 |
