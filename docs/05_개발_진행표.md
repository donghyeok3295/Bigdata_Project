위에서 아래로 진행한다. 각 작업은 **선행 작업이 끝나야 시작**하고 **완료 기준을 만족해야 끝**이다. 관문(G1~G5)에서 전원이 통과 여부를 확인한다.

담당: A 최동혁(데이터·EDA), B 모델·평가, C 교통·기상·공간, D DevOps·서비스
