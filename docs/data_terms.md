# 데이터 이용약관 확인 기록

각 데이터 출처별로 이용약관·라이선스·API 이용 조건을 확인한 결과를 남긴다. 결정 요약은 `docs/DECISIONS.md` D-006 참고.

## 소방청 전국 구급 현황 (bigdata-119.kr)

- **상품 페이지 표기**: 파일유형 CSV, 데이터 제공 방식 다운로드, **이용기간: 구매후 30일까지**, 총 금액 무료, 총 용량 8.02GB
- **확인한 약관**: 소방안전 빅데이터 플랫폼 "판매회원 이용약관"(판매자용, 우리와 무관), "소방안전 빅데이터 플랫폼 이용약관"(일반, 2025-02-17 시행)
- **"30일"의 의미**: 다운로드(재다운로드) 창구가 열려있는 기간이며, 이미 받은 파일의 사용 기한이 아님 — 확인 완료. 한 번 받은 파일은 계속 사용 가능.
- **재사용·공유 제한**: 일반 이용약관 제17조 — 플랫폼에 지적재산권이 귀속된 정보를 사전 승낙 없이 복제·출판·유포하거나 제3자에게 이용하게 하는 것 금지. 상업적 이용 금지(제8조 ⑨).
- **팀 프로젝트 적용 판단**: 비상업적 학술 프로젝트, 팀 내부 공유(팀 드라이브)까지만 허용, 원본 파일은 Git 저장소·외부 서비스에 올리지 않음, 결과물(집계·통계)만 외부 공개. → 상세 근거는 D-006.
- **상태**: ✅ 확인 완료
