# coursework — 수업 과제 전용 폴더

이 폴더에는 **수업 주차별 실습 과제**만 들어 있다. 저장소의 나머지 부분(메인 프로젝트)과는 **별개 작업**이며, 데이터·코드·결과를 공유하지 않는다.

## 경계

- 과제 작업은 **이 폴더 안에서만** 한다. 저장소 루트의 다른 폴더(`src/`, `docs/`, `work/`, `raw/`, `eda/`, `notebooks/`)에는 과제 파일을 만들지 않는다.
- 저장소 루트의 `docs/harness/규칙.md`에 있는 규칙은 **이 폴더에 적용되지 않는다.**
- 메인 프로젝트의 진행 상황이나 데이터를 물었다면 **이 폴더를 보지 않는다.** 반대로 과제 작업에 메인 프로젝트의 데이터·결과를 가져다 쓰지 않는다.

## 과제 목록

각 과제의 진행 상황과 할 일은 해당 폴더의 `README.md`에 있다.
