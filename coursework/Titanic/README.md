# 타이타닉 과제 (중간발표 반영)

> 메인 프로젝트(서울 119 구급)와 무관한 수업 과제다. 상위 `../README.md` 참고.

- **데이터**: `data/train.csv`(891행 × 12열, 정답 있음), `data/test.csv`(418행 × 11열, 정답 없음). 원본은 수정하지 않는다. test는 기초통계·결측 비교와 티켓 일행 수 계산에만 쓰고 모델 평가에는 쓰지 않는다.
- **참고 자료**: `타이타닉 1차.pdf`(기존 1차 분석), `data/*.html`(기존 Q1-Q10 EDA 보고서). 이번 작업과 질문 구성이 다르다.
- **Notion 페이지**: https://app.notion.com/p/407d3b000ed38120ba5ef4b989a53856 (비공개 초안, 중간발표용 정리)

## 교수님 피드백 반영

| 피드백 | 반영 |
| --- | --- |
| 구간마다 인원이 다르면 오차가 달라진다 | 기초통계(분위수)로 경계를 정해 나이 5분위(구간당 138-150명), 요금 4분위로 나눈다. 정수 변수는 값 그대로 보고 30명 미만 집단은 참고로만 표시 |
| 기초통계 먼저 | train/test의 남은 건수·평균·표준편차·사분위·왜도, 범주 구성비를 맨 앞에 둔다 |
| 질문의 가치 검증 후 깊이 | 단변량 χ²·Cramér's V → 성별·등급 통제 후 우도비 검정(Holm 보정). 통과한 질문만 심층 분석 |
| 분석 기준 먼저, 단일 → 복합 질문 | 분석 기준 표를 맨 앞에 두고 질문 10개를 사람 → 동행 → 재력·위치 순으로 연결 |
| 어떤 상황에 어떤 모델인가 | 질문 유형별로 모델을 고른 근거 실험 4개(오즈비, 규칙, 교호작용 재현, 안정성) |

## 실행

```bash
py -3.12 coursework/Titanic/scripts/titanic_eda.py
```

필요 패키지: pandas, numpy, matplotlib, scipy, scikit-learn. 난수 seed=42. 실행은 몇 분 걸린다(중첩 교차검증, 부트스트랩).

| 경로 | 내용 |

| `output/s1-s5_*.png` | 기초통계, 결측, 결측 처리 효과, 영향 요소, 질문 가치 검증 |

## 질문 10개와 가치 검증

| 블록 | 질문 | 성별·등급 통제 후 (Holm p) | 핵심 결과 |
| --- | --- | --- | --- |
| 사람 | Q1 성별×등급 | 교호작용 유의 (5.0e-06) | 여성 96.8·92.1·50.0%, 남성 36.9·15.7·13.5%. 남녀 격차 2등급 76.4%p 최대 |
| 사람 | Q2 호칭 | 유의 (8.1e-09) | Master 57.5%로 Mr 15.7%의 3.7배. 나이 대체 기준 |
| 사람 | Q3 나이 5분위 | 유의 (3.4e-04) | 단독 연관은 약함(V 0.12). 0-18세 남성 33.8%로 다른 연령 남성(10-22%)보다 높음 |
| 동행 | Q4 가족 규모 | 유의 (6.9e-06) | 혼자 30.4% → 3명 57.8% → 5명 이상 16.1%. 비선형 |
| 동행 | Q5 가족 구성 | 근거 부족 (1.00) | 유형 차이는 성별 구성 차이 |

| 동행 | Q7 여성·미성년 | 미성년 유의 (4.5e-03) | 3등급 미성년 35.7%. 5명 이상 가족 미성년 11.4%(35명 중 34명 3등급) |
| 재력·위치 | Q8 요금 | 근거 부족 (0.98) | 1등급 고요금 집단은 여성 62%. 성별 안에서는 요금 차이 없음 |
| 재력·위치 | Q9 객실 기록 | 유의 (0.017) | 사후 기록 가능성 있어 주의 |
| 재력·위치 | Q10 항구 | 근거 부족 (0.075) | 항구 차이는 등급 구성 차이 |

## 한계

- 평가는 train 891명의 교차검증뿐이다. test는 정답이 없고 Kaggle 제출은 하지 않았다.
- 생존율 차이, 오즈비, 규칙은 연관이며 원인이 아니다.
- 객실 기록 유무는 사고 이후 기록일 가능성을 배제할 수 없다.
