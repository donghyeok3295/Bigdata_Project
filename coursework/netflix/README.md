# 5주차 — 결측치 처리 (완료)

## 무엇을 했나

**원칙**: "결측 최소화"는 결측률 수치를 낮추는 것이 아니라 **분석에 실제로 쓸 수 있는 데이터를 늘리는 것**으로 정의했다. 따라서 행 삭제와 `Unknown` 치환은 결측 해결로 보지 않았다.

**결과: 7,787행을 한 건도 삭제하지 않고 결측 셀을 3,631 → 3,556칸으로 줄였다.**

| 컬럼 | 처리 전 | 처리 후 | 방법 |
| --- | --- | --- | --- |
| `director` | 2,389 (30.68%) | 2,389 | 구조적 결측 → 범위 한정 + 플래그 |
| `cast` | 718 (9.22%) | 718 | 구조적 결측 → 범위 한정 + 플래그 |
| `country` | 507 (6.51%) | **439 (5.64%)** | 같은 감독의 다른 작품에서 추론 (68건) |
| `date_added` | 10 (0.13%) | 10 | 추론 근거 없어 미보완 |
| `rating` | 7 (0.09%) | **0** | type+주장르 그룹별 최빈값 |
| (공백) | 89개 셀 | 0 | 앞뒤 공백 정리 → 날짜 파싱 88건 복구 |

## 핵심 발견 3가지

1. **`director` 결측의 93.2%가 TV Show에서 발생** (영화 3.0% vs TV 92.4%) — 시리즈물은 에피소드마다 연출자가 달라 단일 감독을 기재하지 않는 **구조적 공백**. 채우면 안 되고 분석 범위로 대응해야 함.
2. **`cast` 결측도 구조적** — 다큐멘터리 48.3% vs 비다큐 4.8%. 다큐는 배역을 연기하는 출연진이 없는 장르.
3. **삭제·Unknown 치환의 실제 피해를 수치로 확인**
   - 전체 결측 행 삭제 시 TV Show 2,410편 → **135편(생존율 5.6%)**, 비율 30.95% → 2.81%
   - `Unknown` 치환 시 감독 집계에서 **"Unknown"이 2,389편으로 1위** (실제 1위 감독 18편의 133배)

# 6주차 — 10문제 Q&A (완료)

- **문제마다 적은 것**: 사용한 컬럼 / 사용한 행(유효 N) / 전처리 / 도표 기법과 선택 이유 / 결과 표 / 분석 내용

## 교안을 그대로 따르지 않은 곳

- 교안 6-1.2는 국가·장르를 `split(',')[0]`로 첫 값만 쓴다. 공동 제작이 빠져 독일 116%, 캐나다 59%가 누락되므로 4-2처럼 전부 explode했다.
- 교안 5-2, 6-1.1은 상위 5개 등급만 쓴다. 그러면 어린이 등급(TV-Y, TV-Y7, TV-G)이 전부 빠져서 14개 등급을 모두 남겼다.
- 교안 6-3은 워드 클라우드만 그린다. 장르 간 차이가 안 보여서 전체 대비 배수 막대를 같이 그렸다.
